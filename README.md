# روز جملة (Rose Wholesale)

متجر الجملة لروز كتطبيق منفصل عن متجر القطاعي (`rose-store`): قاعدة بيانات مستقلة وحسابات تجار مستقلة ونقاط جملة مستقلة ونشر مستقل على Railway.

## الصفحات

| الصفحة | الرابط |
|---|---|
| شاشة التاجر (تسجيل حساب، دخول، طلب) | `/wholesale/` |
| إدارة الجملة | `/admin/wholesale/` (بتحوّل لـ `/staff-login/` لو مش داخل) |
| دخول الإدارة | `/staff-login/` |
| شاشة الموظفين (تجهيز وتوصيل) | `/pick/` |
| حسابات فريق التاجر | `/wholesale/team/` |
| فحص السيرفر | `/api/health` |

## الحسابات

- **التاجر:** بيسجّل بنفسه من `/wholesale/` برقم الموبايل وكلمة سر (8 حروف على الأقل) واسم المحل والمنطقة. طلبه بيظهر في «التجار ← طلبات الانضمام» ويتوافق عليه. لو نسي كلمة السر، الإدارة بتعمل له «كلمة سر مؤقتة» وهو بيغيّرها أول ما يدخل. 5 محاولات غلط تقفل الحساب ربع ساعة.
- **الإدارة:** دوران: مالك (owner) ومدير (manager). المالك بيضيف ويوقف حسابات الإدارة من «الإعدادات ← حسابات الإدارة». أول مالك بيتعمل من متغيرات البيئة.

## نقاط الجملة

خاصة بالجملة بس، ومالهاش علاقة بنقاط ياسر أو القطاعي.
- التاجر بياخد نقطة لكل N جنيه بعد تسليم الطلب (الإعدادات ← «نقطة لكل كام جنيه»، صفر = مقفولة).
- المرتجع بيسحب نصيبه من النقاط.
- المكافآت بتتعمل من تبويب «النقاط». التاجر بيستبدل من «حسابي» وبياخد كود من 6 أرقام. الإدارة بتدوّر على الكود وبتعلّم إنه «اتسلّمت» أو «إلغاء ورجّع النقاط».
- تعديل يدوي للنقاط من «التجار ← النقاط» جنب كل تاجر.

## متغيرات البيئة

| المتغير | الاستخدام |
|---|---|
| `WHOLESALE_DB_PATH` | مسار قاعدة البيانات. في Docker القيمة `/data/wholesale.db`. الصور والملفات بتتحفظ جنبها في `/data`. |
| `WHOLESALE_OWNER_USERNAME` / `WHOLESALE_OWNER_PASSWORD` / `WHOLESALE_OWNER_DISPLAY_NAME` | أول حساب مالك، بيتعمل عند التشغيل لو مش موجود. |
| `WHOLESALE_COOKIE_SECURE=1` | لازم يتحط في النشر (HTTPS). |
| `WHOLESALE_ENV=production` | وضع النشر. |
| `WHOLESALE_SESSION_DAYS` | مدة دخول التاجر (افتراضي 30 يوم). |
| `WHOLESALE_STAFF_SESSION_HOURS` | مدة دخول الإدارة. |
| `WHOLESALE_TIMEZONE` | المنطقة الزمنية للتقارير (افتراضي `Africa/Cairo`). |

## النشر على Railway

1. خدمة جديدة من الريبو ده (بيبني من `Dockerfile`، والفحص على `/api/health`).
2. Volume على `/data`.
3. المتغيرات اللي فوق، وبعدين الدومين.

> مهم: الـ volume هو اللي فيه كل البيانات. خد نسخة منه قبل أي تحديث كبير.

## التشغيل محليًا

```bash
pip install -r requirements.txt
WHOLESALE_OWNER_USERNAME=owner WHOLESALE_OWNER_PASSWORD='كلمة-سر-قوية' uvicorn app.main:app --reload
pytest
```

## الملفات

- `app/main.py`: التطبيق والصفحات واللوجو.
- `app/db.py`: قاعدة البيانات وجداول الحسابات.
- `app/auth.py`: حسابات الإدارة. `app/customer_auth.py`: حسابات التجار.
- `app/wholesale_points.py`: نقاط الجملة والمكافآت.
- `app/wholesale_*.py`: باقي الجملة (الأصناف، الطلبات، الدفع، التجهيز، التوصيل، المرتجعات، روز بلس، التقارير، النواقص، المحادثات، فريق التاجر).
- `docs/`: مواصفات الجملة وخطة البناء.
